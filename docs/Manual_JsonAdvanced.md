## How to install this module
  
To install the module in Rocketbot Studio, it can be done in two ways:
1. Manual: __Download__ the .zip file and unzip it in the modules folder. The folder name must be the same as the module and inside it must have the following files and folders: \__init__.py, package.json, docs, example and libs. If you have the application open, refresh your browser to be able to use the new module.
2. Automatic: When entering Rocketbot Studio on the right margin you will find the **Addons** section, select **Install Mods**, search for the desired module and press install.  


## Description of the commands

### Add to Json
  
Add a key-value to a Json in a specific path
|Parameters|Description|example|
| --- | --- | --- |
|Json file|Select the Json file where the key-value will be added|Select the Json file|
|Path in Json file|Path in the Json file where the key-value will be added|path in Json file|
|Assign result to variable|Variable where the connection result will be stored|result|
|Key|Write the key that will be added to the Json file|Write the key to add|
|Value|Write the value that will be added to the Json file|Write the value to add|
|Path of the new Json file|Select the path where the new Json file will be saved|Select the path of the new Json file|

### Delete from Json
  
Delete a key-value to a Json in a specific path
|Parameters|Description|example|
| --- | --- | --- |
|Json file|Select the Json file where the key-value will be added|Select the Json file|
|Path in Json file|Path in the Json file where the key-value will be added|path in Json file|
|Key|Write the key that will be deleted from the Json file|Write the key to delete|
|Assign result to variable|Variable where the connection result will be stored|result|
|Path of the new Json file|Select the path where the new Json file will be saved|Select the path of the new Json file|

### Create Json
  
Create a Json file
|Parameters|Description|example|
| --- | --- | --- |
|Json|Write the Json that will be created|Json to create|
|Assign result to variable|Variable where the connection result will be stored|result|
|Path of the new Json file|Select the path where the new Json file will be saved|Select the path of the new Json file|
